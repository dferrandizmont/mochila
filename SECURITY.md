# Security

If you find a security or privacy issue in Mochila, please write to
**privacidad@lamochila.app** instead of opening a public issue. Include the app
version, the steps to reproduce the problem and its possible impact, so it can
be reviewed and fixed before it is made public.

Do not attach real school messages, children's data, phone numbers or e-mail
addresses: reproduce the problem with made-up details.

---

Si encuentras un problema de seguridad o de privacidad en Mochila, escribe a
**privacidad@lamochila.app** en lugar de abrir una incidencia pública. Indica la
versión de la app, los pasos para reproducirlo y su posible impacto. No adjuntes
mensajes reales del cole, datos de los hijos, teléfonos ni correos: reproduce el
problema con datos inventados.
